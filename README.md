Project: Repair Parts – MIS Reporting (Power BI)

Worked on Repair Parts MIS reporting using Power BI to analyze inventory, repair parts consumption, stock movement, and operational performance data. Developed interactive dashboards and automated reports for management to support data-driven decision-making and improve reporting efficiency.

Key Responsibilities:

- Created Power BI dashboards and visual reports for repair parts analysis
- Developed DAX measures and calculated columns for KPI tracking
- Performed data transformation and cleaning using Power Query
- Monitored inventory status, stock aging, shortages, and consumption trends
- Generated daily, weekly, and monthly MIS reports
- Connected and managed data from multiple sources for reporting
- Improved report accuracy and reduced manual effort through automation
- Worked with business teams to understand reporting requirements

Tools & Technologies:

- Power BI
- DAX
- Power Query
- Excel
- SQL
